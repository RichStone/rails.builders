# Resolution: Prototype the Public Rails Builders Experience

The current ruby-red home page, countdown, program explanation, Facilitator section, separate Active/Waitlisted/OG groups, privacy-preserving cards, profile approval flow, and responsive styling are accepted as the v1 experience.
